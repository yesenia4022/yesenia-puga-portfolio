MESA AEW Worksheet Library

A full-stack worksheet library built for MESA students and staff to organize, upload, search, report issues, and receive notifications for AEW math worksheets.

Project Snapshot

  • Role: Sole Developer and Product Designer
  • Timeline: 2025 – Present
  • Tools & Methods: Next.js, TypeScript, Supabase Auth, Supabase Storage, PostgreSQL, Vercel, Resend email API, shadcn/ui, Tailwind CSS
  • Skills Demonstrated: full-stack web development, database design, authentication, storage policies, admin workflows, notification systems, UX design, deployment
  • Status: Working web application used to support worksheet access, staff uploads, issue reporting, and student notifications

Project Description

The MESA AEW Worksheet Library is a web application I built to help students access AEW math worksheets more easily and to give staff a cleaner way to upload, manage, and organize worksheet resources. The project started as a practical solution for MESA students who needed a centralized place to find worksheets by course, professor, category, and date.

The application includes a public worksheet library, staff-only upload tools, worksheet metadata stored in Supabase, PDF storage, issue reporting, and an email notification system that alerts subscribed students when new worksheets are uploaded.

Goals

  • Create a centralized library for AEW worksheets.
  • Allow students to search and filter worksheets by subject and category.
  • Give staff a secure way to upload and manage PDFs.
  • Support solution files and issue reporting for incorrect or missing solutions.
  • Notify subscribed students when new worksheets become available.

Key Features

  • Public worksheet library: Students can browse worksheets by subject and professor.
  • Staff-only uploads: Authorized staff can upload PDFs and add metadata through a protected contribute page.
  • Manage panel: Staff can edit worksheet titles, attach solutions, delete uploads, and review existing records.
  • Report system: Students can report solution issues or website bugs through a dedicated form.
  • Email notifications: Students can subscribe to receive updates when new worksheets are posted.
  • Unsubscribe flow: Students can opt out of notifications through the Help page.

Technical Implementation

I built the application with Next.js using the App Router and TypeScript. Supabase handles authentication, database records, and PDF storage. Worksheet files are stored in a public storage bucket, while metadata is saved in a PostgreSQL table. Staff permissions are controlled through a staff email whitelist and Supabase row-level security policies.

For notifications, I integrated Resend so that students subscribed to a specific subject or professor can receive an email when a matching worksheet is uploaded. I also added server-side routes for bug reports and notifications so that sensitive API keys stay protected.

Tools Used

  • Next.js
  • TypeScript
  • Supabase
  • PostgreSQL
  • Vercel
  • Resend
  • Tailwind CSS
  • shadcn/ui

Outcomes

This project produced a working full-stack web app that supports both students and staff. It made worksheet access more organized for students while giving staff a smoother workflow for uploading, editing, and managing academic resources.

Building this project strengthened my experience with full-stack development, authentication, database-backed applications, file storage, email APIs, and designing tools for real users.
